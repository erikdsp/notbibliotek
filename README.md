# Notbibliotek för orkester

Ett webbaserat notbibliotek som ersätter manuell hantering via Drive-mappar. Noterna organiseras så att aktuella versioner blir lättillgängliga inför spelningar.

Projektet utvecklas som ett praktiskt backendprojekt med fokus på:

- Go
- PostgreSQL
- REST API
- OpenAPI
- React / TypeScript
- testning och CI/CD

## Status

Under utveckling.

Målet är att bygga en fungerande MVP från produktdefinition och API-design till backend, databas och frontend.
